# Web Calculator Project

Created by **Oluwadarasimi Temitope Ajiboye**  
Built with **HTML, CSS, and JavaScript**

## Overview

This is a simple and responsive web-based calculator designed for arithmetic operations. It was originally inspired by a tutorial from GreatStack, but has since been customized with new features to improve usability and visual design.

## Features

- **Modulus Button (MOD):** Allows for modulus operations, useful for CS and math-related tasks.
- **History Panel:** Keeps a log of recent calculations with smooth animation.
- **Animated UI Feedback:** Buttons visually highlight when clicked for responsive user interaction.
- **Clean and Colorful Design:** Styled using a warm pink and coral theme for a friendly, modern look.

## Tech Stack

- **HTML5** – Structure and layout
- **CSS3** – Styling and animations
- **JavaScript (Vanilla)** – Interactivity and logic

## Demo

To run the project locally:

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Use the calculator interface to perform calculations and view history.
